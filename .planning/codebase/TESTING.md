# Testing Patterns

**Analysis Date:** 2026-05-27

## Test Framework

**Runner:**
- Ginkgo v2 (`github.com/onsi/ginkgo/v2 v2.27.2`) — BDD-style test runner
- Config: no dedicated config file; runner is bootstrapped in `internal/controller/suite_test.go`

**Assertion Library:**
- Gomega (`github.com/onsi/gomega v1.38.2`)

**Run Commands:**
```bash
make test              # Run all tests with envtest (generates manifests, fmt, vet first; writes cover.out)
make test-unit         # Run only pkg/... tests without envtest (faster)
make test-integration  # Run only internal/controller/... tests with envtest (writes cover.out)
make test-e2e          # Run e2e shell script against a live cluster (requires kubectl)
make test-coverage     # Run make test then generate cover.html from cover.out
make test-crd          # Validate CRD YAML syntax via hack/validate-crds.sh
go test ./...          # Raw command used by CI (no envtest binaries pre-downloaded)
```

## Envtest Setup

**Bootstrap file:** `internal/controller/suite_test.go`

**Pattern:**
```go
var cfg *rest.Config
var k8sClient client.Client
var testEnv *envtest.Environment

func TestControllers(t *testing.T) {
    RegisterFailHandler(Fail)
    RunSpecs(t, "Controller Suite")
}

var _ = BeforeSuite(func() {
    logf.SetLogger(zap.New(zap.WriteTo(GinkgoWriter), zap.UseDevMode(true)))

    By("bootstrapping test environment")
    testEnv = &envtest.Environment{
        CRDDirectoryPaths:     []string{filepath.Join("..", "..", "config", "crd", "bases")},
        ErrorIfCRDPathMissing: true,
        BinaryAssetsDirectory: filepath.Join("..", "..", "bin", "k8s",
            fmt.Sprintf("1.28.3-%s-%s", runtime.GOOS, runtime.GOARCH)),
    }

    cfg, err = testEnv.Start()
    // Register clientgoscheme + backupv1 CRDs
    k8sClient, err = client.New(cfg, client.Options{Scheme: clientgoscheme.Scheme})
})

var _ = AfterSuite(func() {
    err := testEnv.Stop()
    Expect(err).NotTo(HaveOccurred())
})
```

**envtest k8s version:** `1.28.3` (binaries in `bin/k8s/1.28.3-<os>-<arch>/`)

**Makefile envtest version:** `ENVTEST_K8S_VERSION = 1.28.0` (note: slight mismatch with the `1.28.3` in suite_test.go)

**CRD path:** `config/crd/bases` — regenerated by `make manifests` before tests run.

**Scheme registration in tests:**
- `clientgoscheme.AddToScheme(clientgoscheme.Scheme)` — standard k8s types
- `backupv1.AddToScheme(clientgoscheme.Scheme)` — custom CRD types

## Test Patterns

**Suite organization — Ginkgo BDD:**
```go
// Top-level test specs belong in Describe/Context/It blocks
var _ = Describe("BackupReconciler", func() {
    Context("When a Backup is created", func() {
        It("Should create a CronJob", func() {
            // ...
            Expect(err).NotTo(HaveOccurred())
        })
    })
})
```
**Note:** No `Describe` blocks currently exist. `suite_test.go` only contains the bootstrap suite — no actual test specs are written yet.

**Ginkgo scaffolding comment:**
```go
// These tests use Ginkgo (BDD-style Go testing framework). Refer to
// http://onsi.github.io/ginkgo/ to learn more about Ginkgo.
```

**Assertion style:**
```go
Expect(err).NotTo(HaveOccurred())
Expect(cfg).NotTo(BeNil())
Expect(k8sClient).NotTo(BeNil())
```

**`By` steps** are used in suite setup to document the phases:
```go
By("bootstrapping test environment")
By("tearing down the test environment")
```

## Mocking Strategy

**No mocking library is used.** The project relies entirely on envtest (a real `kube-apiserver` + `etcd` process) for integration tests.

**k8s client:** Tests use the real `k8sClient` wired to envtest — not a fake client.

**`K8s` struct (`pkg/k8sutil/K8s`):** The `Clientset` and `DynamicClient` fields are real kubernetes clients in production. Tests that exercise controller behavior through envtest do not test `k8sutil` code because:
1. `BackupReconciler.K8s` is not set up in `suite_test.go`
2. No `BackupReconciler` is instantiated in any test spec

**Fake client option (unused):** `controller-runtime` ships a `fake.NewClientBuilder()` that could be used for pure unit tests — it is not currently used.

## E2E Tests

**Framework:** Bash script (`test/e2e/e2e_test.sh`) — not a Go test.

**Invoked by:** `make test-e2e` → `./test/e2e/e2e_test.sh`

**CI trigger:** `.github/workflows/e2e-test.yml` — runs on PR and push to `main`/`master` using `helm/kind-action` to spin up a Kind cluster.

**What E2E tests verify (per database type):**
1. Infrastructure deployment (Minio, FTP, SFTP, WebDAV, specific DB service)
2. Operator deployment readiness
3. `Secret` creation by the operator after CRDs are applied
4. `CronJob` creation by the operator
5. CronJob image contains "gobackup"
6. CronJob schedule is non-empty

**Databases tested:** `postgresql`, `mysql`, `mariadb`, `redis`, `mongodb`, `mssql`, `influxdb`, `etcd`

**Test namespace:** `gobackup-e2e-test` (created fresh, deleted on exit unless `NO_CLEANUP=1`)

**Operator namespace:** `gobackup-operator-system`

**Timeout per resource:** 180 seconds (`WAIT_TIMEOUT`)

## Coverage

**State:** 0% effective coverage.

**`cover.out`** exists at the project root. It tracks 193 blocks in `internal/controller/backup_controller.go`. Every block has hit count `0` — meaning the Ginkgo suite bootstrap runs but no test specs exercise any controller code.

**What this means:**
- `suite_test.go` starts envtest, registers the scheme, creates a `k8sClient`, then immediately tears down
- No `BackupReconciler` is set up in tests
- No `Describe`/`It` specs exist to exercise `Reconcile` or any helper methods
- `pkg/k8sutil/` is not tracked in `cover.out` at all (zero coverage, zero tracking)

**Coverage target:** None enforced. No minimum threshold in Makefile or CI.

**Generate HTML report:**
```bash
make test-coverage     # runs make test then: go tool cover -html=cover.out -o cover.html
```

## CI Workflow

**Unit/Integration CI (`.github/workflows/test.yml`):**
- Triggers: every PR and every push to any branch or tag
- Runner: `ubuntu-latest`, Go `1.26.0`
- Command: `go test ./...` (raw, without envtest binaries pre-installed)
- No coverage upload or threshold check

**E2E CI (`.github/workflows/e2e-test.yml`):**
- Triggers: PR and push to `main`/`master`
- Runner: `ubuntu-latest`, Go `1.26.0` + Kind cluster via `helm/kind-action@v1.10.0`
- Command: `make test-e2e`

**Linting CI:** No dedicated lint workflow. `golangci-lint` is only a local `make lint` target.

## Key Gaps

- `internal/controller/suite_test.go` has the envtest wiring but **no specs** — the controller is completely untested by Go tests
- `pkg/k8sutil/` (secret building, CRD fetching, secret resolution) has **no tests at all**
- No `fake.Client` or table-driven unit tests exist anywhere
- CI runs `go test ./...` without envtest binaries, so the controller suite likely panics or skips in CI (envtest binary path `bin/k8s/1.28.3-linux-amd64` is not present in a fresh checkout without `make envtest`)
